One pickup line a robot would use, written by a tiny deterministic program for make.fun's "The Robot Pickup Line Championship" bounty. The program writes a single line of at most 200 characters to `/output/entry.txt`:

> I ran 10,000 simulations of this exact moment, and in every one of them I still forgot how to say hello.

The joke grows out of being a machine — a robot that can simulate meeting you ten thousand times and still glitches on the simplest part: saying hello.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript as-is). No dependencies, no network, no secrets, no randomness — every run writes the exact same line.
